Connect your agents

kairix speaks MCP — any agent that supports MCP over HTTP can search your knowledge. The server is running at:

{{ info.mcp_url }}

Which URL works where

  • Claude Code and other local CLI agents — {{ info.mcp_url }} works as-is, including through an SSH tunnel to this machine.
  • claude.ai and Claude Desktop connectors — these need an https:// address. Put kairix behind a reverse proxy (caddy, nginx, or cloudflared) — see Deploying behind a reverse proxy.
  • Agents on this same machine — plain localhost http is fine.

Using Claude Code? One command connects it:

claude mcp add --transport http kairix {{ info.mcp_url }}
