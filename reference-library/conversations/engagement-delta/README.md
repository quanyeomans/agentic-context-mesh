# engagement-delta

Contradiction / supersession-rich engagement. Four sessions spanning a quarter in which several facts change: agent-beta's role goes from junior to senior; project-rho's status flips from active to on-hold and back to active; an estimate is revised once then revised again; the budget shifts. The corpus exercises the fact-store's supersession logic — for any superseded fact, the latest value should win and the older value should be retrievable as history.
