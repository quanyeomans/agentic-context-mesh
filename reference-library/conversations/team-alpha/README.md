# engagement-alpha

Onboarding-shape engagement. A system-architect briefs agent-alpha on a new fictional customer (client-omega) across four sessions: customer profile, technical stack, current priorities, and team structure. The corpus exercises single-hop entity-attribute retrieval — questions of the form "what is X's Y" where the answer is asserted plainly in one turn — and a small number of multi-hop and adversarial cases to keep the category distribution balanced.
