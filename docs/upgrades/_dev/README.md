# Internal alpha-release development history

This directory holds upgrade notes for **alpha releases** (e.g. `v2026.5.24a1`, `v2026.5.28a1`).

These are internal development snapshots, not operator-facing artefacts. Operators upgrade between **production releases** — see `docs/upgrades/v<year>.<month>.<day>.md` for those.

Each alpha note here documents what changed in that specific alpha so the development team can trace the build-up of a production release after the fact. The rolled-up operator-facing story for the corresponding production release lives in `CHANGELOG.md` and the matching `docs/upgrades/v<stable>.md`.

Do not link to files in this directory from operator-facing docs (CHANGELOG, README, runbooks, OPERATIONS.md).
